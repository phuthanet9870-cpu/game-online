# game-online

โปรเจกต์สำหรับทำเกมออนไลน์บนเว็บหลายเกม โดยใช้เซิร์ฟเวอร์และหน้าเว็บกลางร่วมกัน
เกมแรกคือ **world**: เกมแนว RO แบบ 2.5D เล่นได้หลายคนพร้อมกัน

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

สมัครสมาชิก สร้างตัวละคร แล้วเข้าเกม เปิดหลายแท็บ (หลายบัญชี) เพื่อดูผู้เล่นหลายคนในแผนที่เดียวกัน
ข้อมูลตอน dev เก็บใน `.data/pglite` ไม่ต้องติดตั้งฐานข้อมูล

## รันจริงบนเครื่องเซิร์ฟเวอร์

```bash
npm run build
DATABASE_URL=postgres://user:pass@host:5432/db PORT=2567 npm start   # เปิด http://<เครื่อง>:2567
```

## ทดสอบ

```bash
npm run typecheck
npm test
```

ดูโครงสร้างโปรเจกต์และวิธีเพิ่มเกมใหม่ได้ใน `CLAUDE.md`
