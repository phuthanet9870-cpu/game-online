# game-online

โปรเจกต์สำหรับทำเกมออนไลน์บนเว็บหลายเกม โดยใช้เซิร์ฟเวอร์และหน้าเว็บกลางร่วมกัน
เกมแรกคือ **world**: เกมแนว RO แบบ 2.5D เล่นได้หลายคนพร้อมกัน

## เริ่มใช้งาน

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

เปิดหลายแท็บเพื่อดูผู้เล่นหลายคนเดินและแชทในแผนที่เดียวกัน

## รันจริงบนเครื่องเซิร์ฟเวอร์

```bash
npm run build
PORT=2567 npm start   # เปิด http://<เครื่อง>:2567
```

## ทดสอบ

```bash
npm run typecheck
npm test
```

ดูโครงสร้างโปรเจกต์และวิธีเพิ่มเกมใหม่ได้ใน `CLAUDE.md`
