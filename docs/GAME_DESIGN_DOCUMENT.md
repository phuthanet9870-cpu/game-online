# THE POWER: ETERNAL WAR — Game Design Document

MMORPG × ARPG × PvP × Guild War · Online-first · เล่นบนเบราว์เซอร์ (HTML5) · มุมกล้อง isometric pixel art

## เสาหลัก
1. **ไม่มีคลาส**: บทบาทมาจากอาวุธ 6 ชนิด + The Power + สกิล + ออปชั่น + รูน
2. **Weapon-based combat**: action real-time มีคอมโบ, heavy, dodge (i-frame), block และสกิลอาวุธ 3 สกิล
3. **The Power**: พลังที่ต้องฟาร์มเอง ติดตั้งได้ครั้งละ 1 ผล การเปลี่ยนต้องทำพิธี
4. **โลกใหญ่ + ฟาร์มระยะยาว**: 32 แผนที่ มีบอสที่สุ่มเวลาเกิด และ World Boss ที่ต้องอัญเชิญ
5. **PvP ที่ใช้ฝีมือ + Guild War**: normalization ใน Arena และ scaling/caps ใน Guild War
6. **เศรษฐกิจของผู้เล่น**: ไม่ขายพลังต่อสู้ด้วยเงินจริง
7. **Online-first + กันโกง**: เซิร์ฟเวอร์เป็นผู้ตัดสินทุกอย่าง

## Core loop
เข้าเมือง → เตรียมตัว (ร้านค้า/อุปกรณ์) → ออกฟาร์มในแมพตามเลเวล → ต่อสู้ (หลบ telegraph, คอมโบ, สกิล) → ได้ EXP/ทอง/วัตถุดิบ/Power Fragment → อัปเกรด → แมพยากขึ้น / บอส / ดันเจี้ยน → PvP/Guild War

## ประสบการณ์ที่เล่นได้แล้วใน v0.1
1. สร้างบัญชีและตัวละคร (ดาบหรือคทา) แล้วเกิดที่ Aether Capital
2. คุยกับ NPC ซื้อยา แล้วออกประตูตะวันออกไป Greenfall Plains
3. ฟาร์มสไลม์ เห็ด หมูป่า ภูตแสง หมาป่า เก็บสมุนไพรและแร่ ระวังโคลน แล้วล่า Alpha Wolf (elite)
4. เลเวล 6+ ไป Whispering Forest (หนาม, Elder Sapling)
5. ตายแล้วฟื้นที่เมือง (เสีย EXP 2% ส่วนไอเทมไม่หาย)
6. ออนไลน์: ผู้เล่นหลายคนอยู่ในโลกเดียวกัน แชต และฟาร์มร่วมกัน (EXP แบ่งตามสัดส่วนดาเมจ, ลูตเป็นของคนตีมากสุดเป็นเวลา 30s)

## ความสมดุลโดยรวม
- ตัวละครเลเวล 100 ไม่ควรชนะทุกคนได้โดยไม่ใช้ฝีมือ: PvP มี damage ×0.55, เพดาน DR 75%, caps ของสเตตัส และ normalization ใน Arena (ที่วางแผนไว้)
- การหลบ (i-frame) และ telegraph ทำให้ฝีมือมีผลทั้งใน PvE และ PvP
- ทุก The Power มีจุดเด่น จุดอ่อน และวิธีตอบโต้ (ดู THE_POWER_SYSTEM.md) ไม่มีผลไหนที่ดีที่สุดทั้งตี ป้องกัน และควบคุมพร้อมกัน
