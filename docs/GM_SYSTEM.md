# GM_SYSTEM — ระบบ Game Master

สถานะ: **Tested** (`tests/gm.test.ts`, e2e online)

## การเปิดสิทธิ์
- พิมพ์ในแชต: `/gm<passphrase>` (ไม่เว้นวรรค) เช่น `/gmstefanonline`
- **เซิร์ฟเวอร์เท่านั้น**ที่ตรวจรหัสด้วยการเทียบแบบ constant-time มี rate limit (ใช้ bucket เดียวกับการ login) ทุกครั้งที่ล้มเหลวจะถูกนับเป็น protocol violation และบันทึก `gm_unlock_failed`
- สิทธิ์ผูกกับเซสชัน/ตัวละครที่ออนไลน์อยู่ ไม่ได้บันทึกถาวร ถ้า logout หรือ restart จะต้องปลดล็อกใหม่
- ที่มาของรหัส:
  | โหมด | รหัส |
  |---|---|
  | โหมดในเบราว์เซอร์ (อาร์ติแฟกต์ / Worker) | `stefanonline` (เซิร์ฟเวอร์ส่วนตัวในเครื่องของผู้เล่น) |
  | เซิร์ฟเวอร์ออนไลน์ (Node) | env `GM_PASSPHRASE` ถ้าไม่ได้ตั้งไว้ **GM จะถูกปิด** |

> ⚠️ ห้ามตั้ง `GM_PASSPHRASE=stefanonline` บนเซิร์ฟเวอร์จริง เพราะรหัสนี้อยู่ใน repo และใน JS ของอาร์ติแฟกต์ ทุกคนจึงอ่านเห็นได้

## คำสั่ง (`/gm help`)
| คำสั่ง | ผล |
|---|---|
| `status`, `players`, `zones`, `items [ค้นหา]`, `monsters` | ดูข้อมูล |
| `god`, `invis`, `nocd`, `speed <0.5-5>` | อมตะ / ล่องหน (มอนสเตอร์และผู้เล่นทั่วไปมองไม่เห็น) / ไม่มีคูลดาวน์และไม่ใช้พลังงาน/ยา / ความเร็ว |
| `tp <x> <y> [zone]`, `goto <ชื่อ>`, `summon <ชื่อ>` | วาร์ป / ไปหา / ดึงผู้เล่น |
| `item <id> [qty] [rarity] [ชื่อ]`, `gold <±n> [ชื่อ]` | เสกไอเทม (สร้างบนเซิร์ฟเวอร์ ผ่าน inventory integrity) / ทอง |
| `level <n> [ชื่อ]`, `exp <n> [ชื่อ]`, `mastery <weapon> <lv> [ชื่อ]`, `weapon <type>` | ความก้าวหน้า |
| `heal [ชื่อ]`, `revive [ชื่อ]`, `kill <ชื่อ>` | สถานะชีวิต |
| `spawn <monsterId> [n]`, `killmobs [r]`, `clearmobs [r]`, `respawn` | ควบคุมมอนสเตอร์และแมพ |
| `rates <exp> <drop> <gold>` | ตัวคูณ event ทั้งเซิร์ฟ (0–20) |
| `kick`, `mute <ชื่อ> <นาที>`, `ban <ชื่อ> <ชั่วโมง>`, `unban <username>` | การลงโทษ (ban บันทึกลง DB: migration 2) |
| `announce <ข้อความ>`, `off` | ประกาศ / ปิดสิทธิ์ |

GM Panel (ปุ่ม **GM** มุมขวาบน จะแสดงเมื่อปลดล็อกแล้ว) ส่งคำสั่งชุดเดียวกันนี้ ไม่มีช่องทางลัดอื่น

## ความปลอดภัย
- client ไม่มีทางตั้งค่า flag GM เองได้ ข้อความ `gm` จากเซิร์ฟเวอร์ใช้แค่แสดงผล
- ทุกคำสั่งถูกบันทึก `audit_log` (kind `gm_command`, ข้อความเต็ม)
- มอนสเตอร์ที่ GM เสก (`maxCount 0`) จะถูกลบเมื่อตาย ไม่ไปเพิ่มจำนวน spawn ถาวร
- ช่องว่างที่ทราบ: ยังไม่มีระดับสิทธิ์ GM หลายขั้น (เช่น moderator ทำได้แค่ mute/kick) ควรทำก่อนเปิดเซิร์ฟเวอร์จริง
