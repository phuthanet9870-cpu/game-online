# ENHANCEMENT_SYSTEM (+1 → +20)

สถานะ: **Designed** (ฟิลด์ `enhance` มีอยู่ใน item instance และ DB แล้ว ส่วนวัตถุดิบ Iron Ore ดรอปได้แล้ว)

## ตาราง config เริ่มต้น
| ระดับ | โอกาส | ล้มเหลว | วัตถุดิบ |
|---|---|---|---|
| +1–+5 | 100% | — | Iron Ore |
| +6–+10 | 90, 85, 80, 72, 65% | คงเดิม | Refined Ore |
| +11–+15 | 55, 48, 40, 32, 25% | −1 | Enchanted Ore |
| +16–+19 | 20, 14, 9, 5% | −1 (70%) / −2 (30%) | Legendary Ore |
| +20 | 3% | −2 | Eternal Crystal |

Milestone protection: ระดับจะไม่ต่ำกว่า +5/+10/+15 เมื่อผ่านระดับนั้นมาแล้ว · อุปกรณ์ไม่แตกถาวร · Protection Stone = ไม่ลดระดับ · Blessed Hammer = +X% โอกาส (มีเพดาน) · Pity: ทุกครั้งที่ล้มเหลวที่ระดับเดียวกันจะ +โอกาสสะสม แล้วรีเซ็ตเมื่อสำเร็จ · `enhancement_history` บันทึกทุกครั้ง

## โบนัส
อาวุธ (ATK ฐาน): +2%/lv (1–5), +3% (6–10), +4% (11–15), +5% (16–20) → +20 = +70%
เกราะ/หมวก/ถุงมือ/รองเท้า (DEF/HP): ใช้ครึ่งหนึ่งของอัตราอาวุธ · เครื่องประดับ: เพิ่มสเตตัสรองแบบคงที่ (แยกตาราง ไม่ใช้สูตร ATK)

## PvP
Arena จัดอันดับ: normalize ระดับตีบวกเป็น +10 · Guild War: ใช้ค่าจริงแต่ผ่าน stat scaling (√) และ damage cap ต่อ hit
ทั้งหมดทำบนเซิร์ฟเวอร์ (RNG ฝั่งเซิร์ฟเวอร์ และหักวัตถุดิบกับปรับระดับใน transaction เดียว)
